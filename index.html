Markdown editor · open source

Writing in proportion.

Złoty MD is a Markdown editor with golden ratio proportions and a Google-style color palette — every size, gap and split is a power of φ.

Open web editor

Runs in the browser · installable as an app · MIT License

Everything a technical document needs

Standard Markdown, LaTeX formulas, Mermaid diagrams and highlighted code, rendered live next to your text.

One ratio, all the way down

Interface proportions are based on the golden ratio. The color scheme is inspired by Material Design and Google's palette.

The four Google colours appear in the proportions 1 : 1/φ : 1/φ² : 1/φ³, which add up to √5. Blue is the single accent for actions; red, yellow and green mark state.
